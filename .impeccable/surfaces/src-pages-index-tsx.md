# Landing (/)

Mode : Persuade. Visiteur : joueur de sport entre potes, souvent sur téléphone, arrivé par bouche-à-oreille ou par un lien. Action : télécharger l'app iOS (gratuite). Android/ordinateur : lien secondaire vers la web app pour répondre aux invitations. Aucune preuve sociale réelle : ne rien inventer. Thème clair demandé, identité de l'app (volt #D4FC79, noir #0A0A0A, blanc cassé #FAFAFA, Outfit, objets 3D).

## Direction contract

THESIS: Le visiteur se reconnaît dans le bazar d'un groupe de discussion, puis le voit se ranger en une seule session Sue. On refuse le hero « slogan + mockup de téléphone + grille de fonctionnalités ».

OWN-WORLD: Blanc cassé #FAFAFA, encre #0A0A0A, volt #D4FC79 en aplats (surligneur derrière les mots clés, bande finale entière en volt), gris de bulles #ECECEF. Bulles de discussion génériques (pas de marque WhatsApp), cartes de session blanches à grands rayons comme l'app, avatars à initiales colorées, objets 3D de sport. Outfit 900 serré pour les titres, Outfit 500 pour le texte.

STORY: 1) « C'est mon groupe » 2) la même session devient nette dans Sue 3) chaque galère a sa réponse (liste, date, relances, désistements) 4) tous les sports 5) télécharger.

FIRST VIEWPORT: Colonne gauche : titre géant « Fini les groupes WhatsApp. » (le mot « WhatsApp » barré au feutre volt), sous-titre une phrase, bouton noir « Télécharger sur l'App Store » + mention « Gratuit ». Colonne droite : un fil de groupe qui déborde, bulles empilées et inclinées, pastille de 128 messages non lus. Mobile : titre, bouton, puis le fil.

FORM: « Le groupe WhatsApp qui implose », 1er de ma liste ordonnée, seed 5ceb6f45. Interaction signature : au scroll, section épinglée où les bulles se compressent et s'aspirent dans une carte de session Sue qui se remplit (9/10, « Il manque 1 joueur »).
